GeoCLIP attention-intervention sandbox

Use this tool to compare normal GeoCLIP inference with a run whose vision attention is biased toward or away from selected image regions.

Run an experiment

  1. Upload an image and drag over it to draw one or more regions of interest.
  2. Optionally enter ground-truth latitude and longitude to measure prediction error.
  3. Set a for patches inside the regions and b for patches outside them on any attention layer.
  4. Run inference, then compare the baseline and intervention predictions in the list and map.

Parameters

The values are additive attention-logit biases. Positive values attract attention, negative values repel it, and a = b = 0 leaves a layer unchanged. Equivalent scale is exp(bias).

Notes

Regions are currently drawn manually. Grounding DINO preprocessing is not connected yet.

Saved comparisons stay only in this browser's local storage. This sandbox performs inference only; it does not train or modify model weights.
